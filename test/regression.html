regression over real files

Runs the real pipeline — the same functions app.js calls — over every PDF you pick, and compares the output with the input. Nothing is uploaded and nothing is written to disk; each file is opened, cleaned in memory, measured, and dropped.

fail means the output lost something it should have kept: a page, its geometry, its ink, its text, its navigation — or kept something it should have lost. warn means a human should look: usually text or ink that went at the same time as a watermark, which is either the tool working or the tool overreaching, and only the file can say which.
